# Security Policy

## Supported Versions

Security fixes are prioritized for the latest published release of `@justybase/netezza-driver`. Older versions may not receive backports unless a critical issue warrants it.

## Reporting a Vulnerability

Please report security vulnerabilities privately whenever possible.

1. Prefer [GitHub Security Advisories](https://github.com/justybase/justybase_netezza_node_driver/security/advisories/new) for this repository.
2. If you cannot open a private advisory, open a GitHub issue and mark it clearly as a security concern so maintainers can triage it quickly.

Include as much detail as you can:

- Affected package version(s)
- Impact and attack scenario
- Steps to reproduce or a minimal proof of concept
- Any suggested remediation

We will acknowledge reports as soon as practical, assess the impact, and coordinate a fix and disclosure timeline. Please do not disclose vulnerabilities publicly until a fix is available or maintainers confirm disclosure is appropriate.
